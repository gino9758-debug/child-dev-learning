## 迭代规范

当需要更新本知识库时，遵循以下流程：

1. **信息来源确认**：优先使用吕敏老师个人内容平台或合作机构的一手资料
2. **记录变更**：在迭代记录表中新增一行，注明版本、日期、变更内容和来源
3. **更新对应文件**：
   - 概念性更新 → 同步修改 `lumin_research.md` 和 `SKILL.md` 知识框架
   - 触发场景扩展 → 修改 `SKILL.md` description
   - 新增待补充项 → 追加到本文件"待补充内容"章节
4. **重新打包上传**：修改完成后运行 package_skill.py 重新打包并上传
