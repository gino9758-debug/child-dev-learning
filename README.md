# 儿童发育行为与学能发展

基于吕敏老师研究体系的儿童发育行为与学能发展专业知识库 Skill（Child Development & Learning）

## 项目解决什么问题

孩子"粗心、拖拉、走神、不爱学习、写字慢、错别字多"——很多家长归因于态度或智商，实际可能是神经发育维度滞后。本技能基于吕敏老师研究体系，帮家长理解深层原因、区分"不能学"与"不愿学"，给出分级的家庭干预建议。

## 核心原则

1. **先理解，后归因**：先考虑神经发育滞后，而非简单归因态度/智商
2. **数据说话**：引用研究发生率（感统失调约 5%、读写障碍约 10%、视知觉障碍 15%-30% 等）
3. **区分"不能学"和"不愿学"**：能力上做不到 vs 意愿上不想做
4. **早干预优于晚干预**：0-12 岁干预窗口期，3-6 岁黄金矫正期
5. **三方协作**：家庭 + 学校 + 专业，药物不是唯一手段
6. **安全边界**：提供家庭教育与行为干预建议，不能替代医学诊断；症状严重优先就医

## 知识框架（references/lumin_research）

| 模块 | 覆盖内容 |
|------|---------|
| 发育行为亚健康 | 介于健康与疾病之间的中间状态 |
| 学能七大维度 | 视知觉、听知觉、感觉统合、注意力、动作协调、语言、执行功能 |
| 感统失调 | 前庭觉/本体觉/触觉失调的表现与干预 |
| 视知觉障碍 | 小学低段 15%-30% 发生率，漏题/看错/写字慢的根源 |
| 读写障碍 | 约 10% 学龄儿童，智商正常但需因材施教 |
| ADHD | 5%-10% 发生率，三种亚型及干预原则 |
| 高智商低成就 | 智商 120+ 但成绩垫底的深层原因 |
| 评估与家庭干预 | 何时寻求专业评估、日常活动/教育/饮食作息建议 |

## 安装方法

将本目录放入你的 Agent 技能目录（如 `~/.codex/skills/`、`~/.claude/skills/`），重启会话后生效。

### 要求
- 无第三方依赖

## 使用方法

触发场景：孩子漏题/看错、坐不住/走神、写字慢/错别字多、智商高但成绩差、背了忘/阅读困难、幼小衔接准备、胆小粘人/挑食、经常摔倒/动作笨拙、要不要去医院检查、在家能做什么训练。

## 输入输出示例

**输入：** 孩子总是漏题、看错题目，是粗心吗
**输出：** 视知觉障碍知识定位（发生率 15%-30%）+ 通俗解释 + 家庭干预建议 + 何时需专业评估

**输入：** 孩子智商挺高但成绩垫底，怎么回事
**输出：** 高智商低成就/ADHD/读写障碍的排除分析 + 评估建议 + 家庭支持方案
